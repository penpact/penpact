# Security Policy

Penpact handles documents and signing evidence, so we take security seriously.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Email **security@penpact.dev** with:

- a description of the issue and its impact,
- steps to reproduce (proof-of-concept if possible),
- affected component/version.

We aim to acknowledge reports within 72 hours and will keep you updated on remediation.
Responsible disclosure is appreciated; please give us reasonable time to fix before publishing.

## Supported versions

Penpact is in early development. Until the first tagged release, only the `main` branch is supported.
